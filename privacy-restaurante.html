Política de Privacidad

Compusisnet Restaurante

Última actualización: 27 de septiembre de 2026.

Compusisnet Restaurante es una aplicación diseñada para apoyar la operación y administración de establecimientos de alimentos y restaurantes. La privacidad de nuestros usuarios es importante para nosotros.

Información que utiliza la aplicación

La aplicación puede utilizar información necesaria para identificar al usuario y permitir el acceso a las funciones correspondientes a su cuenta y establecimiento, como dirección de correo electrónico, identificadores de usuario y datos relacionados con la operación del negocio.

Inicio de sesión y autenticación

Compusisnet Restaurante utiliza servicios de autenticación para permitir el acceso seguro a la aplicación. También puede utilizar autenticación biométrica disponible en el dispositivo, cuando el usuario decide utilizarla.

Uso de la cámara

La aplicación puede solicitar acceso a la cámara del dispositivo para funciones como escaneo de códigos y otras operaciones relacionadas con productos. La cámara solamente se utiliza cuando el usuario accede a una función que la requiere.

Imágenes y archivos

Algunas funciones pueden permitir seleccionar o almacenar imágenes relacionadas con categorías, productos u otros elementos utilizados dentro del sistema.

Datos del negocio

La aplicación puede procesar información relacionada con la operación del establecimiento, incluyendo categorías, productos, mesas, comandas, ventas y otros datos necesarios para proporcionar las funciones del sistema.

Servicios de terceros

Compusisnet Restaurante utiliza servicios tecnológicos de terceros, incluyendo servicios de Google Firebase, para funciones como autenticación, almacenamiento y manejo de información necesaria para el funcionamiento de la aplicación.

Seguridad

Se toman medidas razonables para proteger la información utilizada por la aplicación y limitar su acceso a usuarios autorizados.

Menores de edad

Compusisnet Restaurante está diseñada como una herramienta de trabajo para establecimientos comerciales y no está dirigida específicamente a menores de edad.

Cambios a esta política

Esta política de privacidad puede actualizarse cuando se incorporen nuevas funciones o cambien los servicios utilizados por la aplicación. Las modificaciones serán publicadas en esta misma página.

Contacto

Para preguntas relacionadas con esta política de privacidad o con el uso de información dentro de Compusisnet Restaurante, puedes comunicarte con nosotros a través de los medios de soporte proporcionados por Compusisnet.
